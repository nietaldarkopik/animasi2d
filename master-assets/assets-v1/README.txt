Aset Karakter Builder - SMK Informatika
- Semua PNG latar transparan, dipertajam 4x (anime upscaler) dari lembar asli 1536x1024.
- Folder per kategori: rambut_depan, rambut_belakang, wajah, mata (sepasang kiri+kanan), alis (sepasang),
  mulut, kemeja, jaket, celana, rok, kerudung, aksesoris, sepatu, pose (karakter utuh), ekspresi (kepala utuh).
- manifest.json : daftar file per kategori (bisa langsung dipakai di kode builder).
- palette.json  : kode warna hex dari panel Warna (kulit, rambut, mata, pakaian).
- _preview.png  : lembar pratinjau semua aset.
Catatan: aset dipotong dari ilustrasi, jadi tiap bagian belum memiliki titik jangkar (anchor) yang seragam;
atur posisi/skala per kategori di builder.
